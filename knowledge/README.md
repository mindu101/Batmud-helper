# Knowledge Index

These notes are a work in progress. The live game and dated source captures outrank memory or inference.

Use [quick-reference.md](quick-reference.md) as the compact context entry point. When a short note is insufficient, query the relevant `help <topic>` in game, preserve the source output, and add a concise summary here.

- [Commands](commands.md): verified command families and help topics.
- [World](world.md): setting, continents, factions, and lore.
- [Areas](areas.md): rooms, routes, maps, and travel hazards.
- [Equipment](equipment.md): item inspection, armor, weapons, and loadouts.
- [Progression](progression.md): experience, levels, training, guilds, and advancement.
- [Merchant career](merchant-guide.md): external merchant guides, economic loops, and current verification checklist.
- [Merchant race comparison](../research/race-comparison.md): provisional race shortlist for the planned reincarnation.
- [Strategy](strategy.md): combat, survival, economy, and repeatable walkthroughs.
- [Character profile](character-profile.md): dated character facts and goals.

For every recommendation, record its prerequisites, the exact command or action, the observed result, date, and source. Do not infer an item's usefulness from its name alone.
