### portcullis
- **读音**:/ˈpɔːtkʌlɪs/"波特-卡利斯",重音在前
- **词性**:名词(可数,portcullises)
- **这句话里的意思**:铁闸门——中世纪城堡那种可以升降的铁栅栏门
- **游戏原句**:`Iron portcullis (closed) leads south.`(seq 42,
  你的出生点 Dortlewall 北门楼的房间描述)
- **整句翻译**:一道铁闸门(关着)通向南方。
- **其他常见义**:基本只有"闸门"一个意思,奇幻/历史题材高频词
- **相关词**:gate 大门 / drawbridge 吊桥 / rampart 城墙 / moat 护城河
- **场景记忆**:你每次 `look` 都能看到它——它就是你出生房间朝南的门,
  想出城就得经过这道"portcullis"
